# Coreutils Specification

This directory contains the downloaded versions of the POSIX and GNU specs /
manuals of the core utilities. The original specs are distributed in HTML;
they were converted to markdown to save some tokens, and only the markdown
copies are kept here.

The original archives are available for download here:

* [POSIX](https://pubs.opengroup.org/onlinepubs/9799919799/download/index.html)
* [GNU](https://www.gnu.org/software/coreutils/manual/)
