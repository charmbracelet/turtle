# Coreutils Specification

This directory contains the downloaded versions of the POSIX and GNU specs /
manuals of the core utilities. The original specs are in HTML but we also
converted them to markdown to allow saving some tokens.

You can find the orignal archives for download here:

* [POSIX](https://pubs.opengroup.org/onlinepubs/9799919799/download/index.html)
* [GNU](https://www.gnu.org/software/coreutils/manual/)
