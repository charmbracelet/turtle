# Basic operations (GNU Coreutils 9.12)
## 11 Basic operations

This chapter describes the commands for basic file manipulation:
copying, moving (renaming), and deleting (removing).

* [`cp`: Copy files and directories](cp-invocation.md)
* [`dd`: Convert and copy a file](dd-invocation.md)
* [`install`: Copy files and set attributes](install-invocation.md)
* [`mv`: Move (rename) files](mv-invocation.md)
* [`rm`: Remove files or directories](rm-invocation.md)
* [`shred`: Remove files more securely](shred-invocation.md)
