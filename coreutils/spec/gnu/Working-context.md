# Working context (GNU Coreutils 9.12)
## 19 Working context

This section describes commands that display or alter the context in
which you are working: the current directory, the terminal settings, and
so forth. See also the user-related commands in the next section.

* [`pwd`: Print working directory](pwd-invocation.md)
* [`stty`: Print or change terminal characteristics](stty-invocation.md)
* [`printenv`: Print all or some environment variables](printenv-invocation.md)
* [`tty`: Print file name of terminal on standard input](tty-invocation.md)
