# Output of entire files (GNU Coreutils 9.12)
## 3 Output of entire files

These commands read and write entire files, possibly transforming them
in some way.

* [`cat`: Concatenate and write files](cat-invocation.md)
* [`tac`: Concatenate and write files in reverse](tac-invocation.md)
* [`nl`: Number lines and write files](nl-invocation.md)
* [`od`: Write files in octal or other formats](od-invocation.md)
* [`base32`: Transform data into printable data](base32-invocation.md)
* [`base64`: Transform data into printable data](base64-invocation.md)
* [`basenc`: Transform data into printable data](basenc-invocation.md)
