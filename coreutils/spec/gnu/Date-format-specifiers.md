# Date format specifiers (GNU Coreutils 9.12)
#### 21.1.1 Specifying the format of `date` output

If given an argument that starts with a ‘`+`’, `date` prints the
date and time in the format defined by that argument,
which is similar to that of the `strftime` function. Except for
conversion specifiers, which start with ‘`%`’, characters in the
format string are printed unchanged. The conversion specifiers are
described below.

* [Time conversion specifiers](Time-conversion-specifiers.md)
* [Date conversion specifiers](Date-conversion-specifiers.md)
* [Literal conversion specifiers](Literal-conversion-specifiers.md)
* [Padding and other flags](Padding-and-other-flags.md)
