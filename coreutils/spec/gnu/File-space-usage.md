# File space usage (GNU Coreutils 9.12)
## 14 File space usage

No file system can hold an infinite amount of data. These commands report
how much storage is in use or available, report other file and
file status information, and write buffers to file systems.

* [`df`: Report file system space usage](df-invocation.md)
* [`du`: Estimate file space usage](du-invocation.md)
* [`stat`: Report file or file system status](stat-invocation.md)
* [`sync`: Synchronize cached writes to persistent storage](sync-invocation.md)
* [`truncate`: Shrink or extend the size of a file](truncate-invocation.md)
