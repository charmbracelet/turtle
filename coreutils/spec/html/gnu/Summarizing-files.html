6 Summarizing files ¶

These commands generate just a few numbers representing entire contents of files.

  • wc: Print newline, word, and byte or character counts
  • sum: Print checksum and block counts
  • cksum: Print and verify file checksums
  • md5sum: Print or check MD5 digests
  • b2sum: Print or check BLAKE2 digests
  • sha1sum: Print or check SHA-1 digests
  • sha2 utilities: Print or check SHA-2 digests
