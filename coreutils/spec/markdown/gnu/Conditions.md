# Conditions (GNU Coreutils 9.12)
## 16 Conditions

This section describes commands that are primarily useful for their exit
status, rather than their output. Thus, they are often used as the
condition of shell `if` statements, or as the last command in a
pipeline.

* [`false`: Do nothing, unsuccessfully](false-invocation.md)
* [`true`: Do nothing, successfully](true-invocation.md)
* [`test`: Check file types and compare values](test-invocation.md)
* [`expr`: Evaluate expressions](expr-invocation.md)
