# Output of parts of files (GNU Coreutils 9.12)
## 5 Output of parts of files

These commands output pieces of the input.

* [`head`: Output the first part of files](head-invocation.md)
* [`tail`: Output the last part of files](tail-invocation.md)
* [`split`: Split a file into pieces.](split-invocation.md)
* [`csplit`: Split a file into context-determined pieces](csplit-invocation.md)
