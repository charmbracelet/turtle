# Summarizing files (GNU Coreutils 9.12)
## 6 Summarizing files

These commands generate just a few numbers representing entire
contents of files.

* [`wc`: Print newline, word, and byte or character counts](wc-invocation.md)
* [`sum`: Print checksum and block counts](sum-invocation.md)
* [`cksum`: Print and verify file checksums](cksum-invocation.md)
* [`md5sum`: Print or check MD5 digests](md5sum-invocation.md)
* [`b2sum`: Print or check BLAKE2 digests](b2sum-invocation.md)
* [`sha1sum`: Print or check SHA-1 digests](sha1sum-invocation.md)
* [sha2 utilities: Print or check SHA-2 digests](sha2-utilities.md)
