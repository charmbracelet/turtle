# whoami invocation (GNU Coreutils 9.12)
### 20.3 `whoami`: Print effective user name

`whoami` prints the user name associated with the current
effective user ID. It is equivalent to the command ‘`id -un`’.

The only options are `--help` and `--version`. See [Common options](Common-options.md).

An exit status of zero indicates success,
and a nonzero value indicates failure.
