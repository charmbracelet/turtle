# System context (GNU Coreutils 9.12)
## 21 System context

This section describes commands that print or change system-wide
information.

* [`date`: Print or set system date and time](date-invocation.md)
* [`arch`: Print machine hardware name](arch-invocation.md)
* [`nproc`: Print the number of available processors](nproc-invocation.md)
* [`uname`: Print system information](uname-invocation.md)
* [`hostname`: Print or set system name](hostname-invocation.md)
* [`hostid`: Print numeric host identifier](hostid-invocation.md)
* [`uptime`: Print system uptime and load](uptime-invocation.md)
