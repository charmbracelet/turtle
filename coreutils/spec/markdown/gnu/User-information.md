# User information (GNU Coreutils 9.12)
## 20 User information

This section describes commands that print user-related information:
logins, groups, and so forth.

* [`id`: Print user identity](id-invocation.md)
* [`logname`: Print current login name](logname-invocation.md)
* [`whoami`: Print effective user name](whoami-invocation.md)
* [`groups`: Print group names a user is in](groups-invocation.md)
* [`users`: Print login names of users currently logged in](users-invocation.md)
* [`who`: Print who is currently logged in](who-invocation.md)
* [`pinky`: Print information about users](pinky-invocation.md)
